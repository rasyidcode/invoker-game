## Issue Report Template

When logging a new issue, ensure it follows this standard structure:
- **Status & Metadata**: Open/Resolved, Severity, Affected Platforms, Discovered In.
- **Summary**: High-level problem statement.
- **Steps to Reproduce**: Minimal steps to trigger the bug.
- **Observed Behavior vs Expected Behavior**.
- **Technical Root Cause Analysis**: Code symbols, file paths, line references, and execution path.
- **Proposed Fix**: Actionable resolution steps.
